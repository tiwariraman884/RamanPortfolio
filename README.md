# Raman Kumar Tiwari - Personal Portfolio

Welcome to the repository for my personal portfolio website! This project is built using modern web technologies to showcase my projects, experience, skills, and certifications.

## 🚀 Overview

I'm Raman Kumar Tiwari, a Computer Science student at Roorkee Institute of Technology, developer, hackathon builder, and AI enthusiast. This portfolio is designed to be interactive and engaging, serving as a hub for my real-world projects and achievements.

## 🛠️ Tech Stack

This project was bootstrapped with [Vite](https://vitejs.dev/) and is built with:

- **Frontend Framework:** React 19
- **Animations:** Framer Motion
- **3D Graphics:** Three.js & React Three Fiber
- **Icons:** Lucide React
- **Styling:** CSS
- **Linting:** ESLint

## 💻 Running Locally

To run this project on your local machine, follow these steps:

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port provided by Vite).

## 🔨 Build for Production

To create a production-ready build:
```bash
npm run build
```

This will generate a `dist` folder containing the optimized static assets.
